## `<notifications>`

`<notifications>`: local notifications for apps on eskiu-lang/ui. The app schedules one with
a title and a body for a number of seconds from now; the system shows it then, also when the
app is in the background or closed, and tells the app when the user opens it. The platform's
own service keeps them: UNUserNotificationCenter on iOS, AlarmManager and NotificationManager
on Android, the Notification API on the web (there only while the page is open).

### NotificationPermission

```eskiu
enum NotificationPermission { NotificationsChecking, NotificationsNotAsked, NotificationsAllowed, NotificationsDenied }
```

Whether the app may show notifications: not known yet (the platform has not answered),
never asked, allowed, or denied.

### notifications_read_permission

```eskiu
bool notifications_read_permission(string payload)
```

A message on the "notifications" channel about the permission into notifications_permission;
false for any other message.

### use_notification_permission

```eskiu
int use_notification_permission()
```

Whether the app may show notifications, while the scope is mounted: NotificationsChecking
until the platform answers, then NotificationsNotAsked, NotificationsAllowed or
NotificationsDenied. The scope renders again when it changes.

### notifications_ask

```eskiu
void notifications_ask()
```

Ask the user to allow notifications (the system asks once; after that it answers with what
the user chose). The answer reaches use_notification_permission.

### notification_schedule

```eskiu
void notification_schedule(string id, string title, string body, int seconds)
```

Show a notification `seconds` from now (at least 1), with `id` to cancel or replace it: one
scheduled with the same id replaces it. Without the permission the system drops it.

### notification_cancel

```eskiu
void notification_cancel(string id)
```

Cancel a scheduled notification, and take it away if it is showing.

### NotificationOpened

```eskiu
struct NotificationOpened { fn(string)->void handler; }
```

The latest render's handler, kept in the hook's slot.

### use_notification_opened

```eskiu
void use_notification_opened(escaping fn(string)->void on_open)
```

`on_open` gets the id of each notification the user opens while the scope is mounted, and,
when it mounts, the one that opened the app, if any (only the first handler to mount gets
that one).
